# Circuits Circus

A no-install browser game for practicing Thevenin equivalent circuits.

## Play

Open `index.html` in a browser. Work through six acts:

1. Remove the load.
2. Find open-circuit voltage.
3. Deactivate the independent source.
4. Find Thevenin resistance.
5. Reconnect the load and find its current.

You have three lives and 25 seconds per question. Use the mouse or keys **1–4** to answer. Hints cost 25 points. Your best score is saved in your browser.

## Circuit assumptions

All sources and resistors are ideal. Resistances are shown in kΩ, so volts divided by kΩ gives mA. The game covers voltage dividers, a series resistor at an open output, a simple series source, and Norton source transformations.

## Tech

Plain HTML, CSS, and JavaScript. No installation, dependencies, API keys, or build step.
